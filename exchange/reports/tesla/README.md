# Предложения Тесли

Здесь Тесля документирует анализ задач и варианты решения до допуска к исполнению.

Каждый отчёт должен содержать:

- постановку задачи;
- проверенные факты;
- рассмотренные варианты;
- рекомендуемое решение;
- риски и ограничения;
- необходимые проверки;
- границы компетенции и причины эскалации, если она нужна;
- следующий шаг.

Документ предложения не означает, что решение принято к исполнению.
