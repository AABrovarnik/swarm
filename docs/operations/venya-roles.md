# Карта ролей и Telegram-дверей (канон)

Этот документ фиксирует, какой Telegram-бот за какой ролью закреплён, и какие у каждой роли полномочия.

| `chat_id=228518784` (`@BrOVArNiK_Al`) | — | Александр | Владелец решений, постановщик задач |

`@S_Nail_Bot` — отдельная задача, в колхоз не входит.

## Правила

- Один бот — одна роль. У каждой роли свой Telegram-фасад и свой числовой ID.
- Никаких переодевалок и режимов «а теперь побрейся».
- Веня остаётся единой точкой входа для задач.
- Прямая дверь к Изе (`@AlexBrew_Bot`) — только для аварии, конфиденциального вопроса или явного обхода диспетчерской по решению Александра.
- Числовой ID фиксируется в конфиге каждого бота как `BOT_ID=<числовой_id>`, чтобы при логах и отладке не путать двери.
- `ALLOWED_CHAT_ID` для каждого бота — это список личных `chat_id` тех, кто может слать ему задачи напрямую (для Вени — это `228518784` Александра; для Тесли и Студента — уточняется отдельно).

## Что НЕ допускается

- Назначать одной роли два Telegram-фасада.
- Переключать роль внутри одного бота командами `/role` или текстовыми триггерами.
- Использовать `@S_Nail_Bot` в контуре колхоза.
- Путать `chat_id=228518784` (Александр) с числовым ID бота Изи `8749010398`.
